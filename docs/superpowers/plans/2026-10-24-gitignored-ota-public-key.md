# Gitignored OTA Public Key Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Read the 32-byte Ed25519 OTA public key from gitignored binary files (`ota_public_key.bin`) at compile time in both `intercom-matter` and `hvac-bridge`, automating extraction from local private keys with `generate_keys.py`.

**Architecture:** Instead of committing the 32-byte key array directly in `src/config.rs`, `OTA_PUBLIC_KEY` is loaded via Rust's compile-time `*include_bytes!("../ota_public_key.bin")`. The key file is generated by `scripts/generate_keys.py` and excluded from source control via `.gitignore`.

**Tech Stack:** Rust (`no_std`, bare-metal RISC-V), Python 3 (`cryptography` library), Cargo, mise.

## Global Constraints

- Never commit private keys (`ota_key.pem`) or public keys (`ota_public_key.bin`) to git.
- The binary public key file must be exactly 32 bytes (`[u8; 32]`).
- Do not add new external crates or build dependencies.
- Maintain existing APIs (`config::OTA_PUBLIC_KEY: [u8; 32]`).

```python
#!/usr/bin/env python3
"""Generate an Ed25519 key pair for Smart Intercom OTA firmware signing."""

import sys
from pathlib import Path

try:
    from cryptography.hazmat.primitives.asymmetric import ed25519
    from cryptography.hazmat.primitives import serialization
except ImportError:
    sys.stderr.write(
        "Error: 'cryptography' library is not installed.\n"
        "Please install it using: pip3 install cryptography\n"
    )
    sys.exit(1)

KEY_DIR = Path.home() / ".intercom"
KEY_PATH = KEY_DIR / "ota_key.pem"
REPO_ROOT = Path(__file__).resolve().parent.parent
BIN_KEY_PATH = REPO_ROOT / "crates" / "intercom-firmware" / "ota_public_key.bin"


def main():
    KEY_DIR.mkdir(parents=True, exist_ok=True)
    if KEY_PATH.exists():
        print(f"Key already exists at {KEY_PATH}")
        with open(KEY_PATH, "rb") as f:
            private_key = serialization.load_pem_private_key(f.read(), password=None)
    else:
        private_key = ed25519.Ed25519PrivateKey.generate()
        pem = private_key.private_bytes(
            encoding=serialization.Encoding.PEM,
            format=serialization.PrivateFormat.PKCS8,
            encryption_algorithm=serialization.NoEncryption(),
        )
        with open(KEY_PATH, "wb") as f:
            f.write(pem)
        KEY_PATH.chmod(0o600)
        print(f"Generated new Ed25519 private key: {KEY_PATH}")

    public_key = private_key.public_key()
    pub_bytes = public_key.public_bytes(
        encoding=serialization.Encoding.Raw,
        format=serialization.PublicFormat.Raw,
    )

    BIN_KEY_PATH.parent.mkdir(parents=True, exist_ok=True)
    BIN_KEY_PATH.write_bytes(pub_bytes)
    print(f"Wrote 32-byte public key binary to {BIN_KEY_PATH}")


if __name__ == "__main__":
    main()
```
