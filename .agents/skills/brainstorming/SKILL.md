# Brainstorming (Disabled for OpenSpec)

This project uses **OpenSpec** for all requirement exploration, design, and change planning.
The global Superpowers `brainstorming` skill is intentionally disabled and shadowed here.

## What to Use Instead

- **To explore ideas, clarify requirements, or think through problems:**
  Use the [`openspec-explore`](../openspec-explore/SKILL.md) skill.
- **To create a formal proposal, architecture design, and tasks:**
  Use the [`openspec-propose`](../openspec-propose/SKILL.md) skill.
- **To update an active change:**
  Use the [`openspec-update-change`](../openspec-update-change/SKILL.md) skill.

Do not create `docs/superpowers/specs/` files or run the brainstorming checklist in this workspace.
